# ContextBridge v0.3.0 — Release notes

**Release date:** 2026-11-15

ContextBridge is an offline-first, MIT-licensed Python command-line tool for
explicit, reviewable handoffs between AI coding agents. No API keys or hosted
AI services are required for the CLI.

## What's new

- **Structured task progress:** record a task status (`planned`,
  `in_progress`, `blocked`, `done`) and up to eight bounded next steps.
  Refreshing snapshots keeps fields that were not explicitly changed.
- **Optional Git context:** `contextbridge export --git` adds current
  revision, safe branch name and dirty-tree indicator. This never includes
  source-code diffs, Git remotes, commit messages or Git file paths.
- **Compatibility:** existing v0.2 snapshots remain readable.
- **Documentation:** added a reproducible coding-agent handoff walkthrough.
- **Regression testing:** additional validation, privacy, legacy-snapshot and
  cross-platform tests.

## Try it

Use a clean checkout of this tag (when it is published), with Python 3.10 or
newer. From the repository directory:

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
contextbridge --help
```

Inside a project directory:

```bash
contextbridge init
contextbridge snapshot --task "Review project" --task-status in_progress --next-step "Run tests"
contextbridge export --target codex --git --output handoff-codex.md
```

Review any handoff before sharing it with a model or another person.

## Security and limitations

- Project files are scanned to compute bounded hashes, but source contents are
  not included in handoff exports.
- Notes, paths and optional branch names can contain private information.
  Secret detection is heuristic, **not** a confidentiality guarantee.
- Handoffs are untrusted context. They do not authorize coding agents to run
  commands or edit files.
- ContextBridge does not automatically synchronize agent chats or accounts.
- The Python package version alone does not constitute a GitHub release:
  publish a matching `v0.3.0` tag and release after CI verification.
