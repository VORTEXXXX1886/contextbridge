# Contributing

ContextBridge aims to make coding-agent handoffs safer, simpler, and reproducible. Bug reports, regression tests, and documentation improvements are welcome.

1. Open an issue before substantial changes.
2. Use a focused branch, with minimal external dependencies.
3. Run `python -m unittest discover -s tests -v`.
4. Add tests for security-sensitive or bug-fix changes.
5. Open a pull request with the motivation, test results, and compatibility risks.

Never post credentials, private conversation histories, or sensitive handoffs in public issues.
